## Запуск из корня проекта

Зависимости закреплены в `experiment/requirements.txt`. Нужны клипы из `experiment/clips.json` в корне проекта (`clip_1.mp4` и т. д.), `experiment/results.json` от первого прогона и `experiment/yunet.onnx`.

```sh
.venv/bin/python experiment/panel_probe.py
.venv/bin/python experiment/panel_report.py
.venv/bin/python -m unittest discover -s experiment -p 'test_panel_probe.py'
```

`panel_probe.py --skip-dense` пропускает дополнительные локальные сэмплы. Алгоритм не скачивает видео и не обращается к внешним API.

## Артефакты

- `panel_probe.py` — поиск угловой панели, проверка текущих границ и сходства содержимого, отказ от результата при недостаточных свидетельствах.
- `panel-results.json` — 144 базовых и, при обычном запуске на текущих входах, 36 дополнительных сэмплов. Содержит параметры, debug-признаки, actual/requested timestamps, причины решений.
- `panel-reference.json` — 50 независимых ручных аннотаций; **не читается inference-кодом**.
- `panel_report.py`, `panel-evaluation.json` — сравнение с разметкой (IoU≥0.90, ошибки сторон, пропуски и ложные bbox).
- Локальные (исключены из git): `panel-report.html`, `report.html`, `panel-preview.jpg`, `*-panel-*.jpg` и сгенерированные кадры.
- `test_panel_probe.py` — синтетические unit-тесты без чтения реальных видео/разметки.
- `clips.json` — локальный список клипов: метки `clip_N` и имена файлов, без источника, названия и ссылок.

## Контракт

`frames` — исходные сэмплы; `dense_frames` — локальные дополнительные, `index=null` и отдельный `sample_id`. Для обоих:

- `detected`: `bbox_px=[x,y,width,height]` в исходном разрешении, `webcam={x,y,w,h}` в долях кадра. Правая/нижняя границы исключающие.
- `ambiguous` / `not_detected`: `bbox_px=null`, `webcam=null`. `not_detected` означает нехватку свидетельств, а не доказанное отсутствие вебки.
- `candidate_bbox_normalized` — **только debug-гипотеза**, не подтверждённая панель. При отказе её нельзя использовать как crop.
- `face_in_candidate` — центр хотя бы одного bbox лица внутри гипотезы; это не identity/ground truth.
- `evidence` — поддержка сторон и расстояние до appearance-образцов. Score не вероятность.

## Ограничения

Это offline development-эксперимент на трёх известных видео. Основная геометрия и банк образцов используют весь ролик, включая будущие кадры. Текущий базовый сэмпл исключается из своего appearance-сравнения, но это **не** train/test split: геометрия всё равно оценивается по совокупности кадров.

Поддерживаются только прямоугольные панели с двумя сторонами на краях кадра. Нет свободных панелей, chroma key, кругов, нескольких ведущих, непрерывного трекинга или точных временных сегментов. Локальный поиск допускает изменение размеров в пределах ±25% от основной геометрии.

При сильном изменении освещения/содержимого возможен отказ. Найденная рамка вместе со сходством содержимого не доказывает семантически, что это именно текущая вебка ведущего. Независимая разметка на этих же development-видео — не независимый benchmark; три отсутствующих панели слишком мало для оценки false-positive rate в общем случае.
